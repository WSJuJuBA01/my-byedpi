📖 О проекте
Custom ByeDPI — это мобильное приложение для обхода систем глубокого анализа трафика (DPI / ТСПУ). В отличие от стандартных решений, приложение использует собственное легковесное C-ядро, выполняющее локальную фрагментацию TLS Client Hello на уровне TCP-пакетов без отправки трафика на внешние сервера.

📱 Проект полностью разработан, скомпилирован и протестирован на Android-устройстве.

✨ Особенности
 * 🚀 Собственное C-ядро: Минимальное потребление ОЗУ и батареи.
 * 🔀 Раздельное тоннелирование (Split Tunneling): Выбирай, какие приложения отправлять через туннель (например, YouTube/Discord), а какие пускать напрямую (Банки, Госуслуги).
 * 🔒 Полная приватность: Весь трафик обрабатывается локально на устройстве (127.0.0.1). Нет внешних VPN-серверов.
 * 🛠️ Гибкая фрагментация: Поддержка смещения split-pos, деления заголовков HTTP/TLS и смены порядка отправки пакетов.
 * ⚡ Без Root-прав: Работает через стандартный Android VpnService.
